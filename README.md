# MHO Party Bot

Discord 上で、1サーバーごとの4人パーティを募集するボットです。募集データは SQLite に残り、毎週日曜 0:00（日本時間）にすべて解散します。別のサーバーのパーティは、一覧にも掲示板にも出ません。

## コマンド

| コマンド | 誰に見えるか | 内容 |
| --- | --- | --- |
| `/party create` | 全員（ephemeral はオフ固定） | パーティ名（必須、80文字以内）とメモ（任意、300文字以内）で募集を作る。作成者はリーダー兼メンバー。参加と退出のボタンが付く |
| `/party delete` | 実行した人だけ | 自分が作成した募集を、引数なしで削除する。リーダーが移っていても、削除できるのは作成者だけ |
| `/party list` | 規定では実行した人だけ | 今いるサーバーの募集を Components V2 で表示する。`ephemeral` をオフにするとチャンネル全員に見える |
| `/party board` | 返事は実行した人だけ。掲示板本体はチャンネルに残る | 実行したチャンネルに掲示板を貼る。再実行すると、古い掲示板を消して今のチャンネルへ移す |

参加と退出の結果も、押した人だけに表示します。公開カードと掲示板は、そのたびに最新の人数へ更新します。

## ルール

- 定員は4人です。満員の参加ボタンは押せません。
- 1人の作成者につき、同じサーバーで募集は1件までです。作り直すときは `/party delete` してから `/party create` します。
- リーダーが退出すると、残っているメンバーのうち参加が最も早い人へリーダーが移ります。同時刻のときはユーザーIDが小さい人です。
- リーダーが抜けて誰も残らないと、そのパーティは解散します。
- 作成者が抜けても削除権は作成者のままです。移譲先のリーダーは `/party delete` できません。
- ボタンは、そのパーティが作られたサーバーでだけ有効です。

## 掲示板

`/party board` は、募集専用のチャンネルで実行する想定です。作成、削除、参加、退出、日曜の解散のたびに、同じメッセージを編集します。6件を超えると、同じチャンネルに次のメッセージを足します。掲示板からも参加と退出ができます。

`/party list` はボタンのない一覧です。文字数に収まらない分は、掲示板で確認する案内になります。

## 日曜リセット

毎週日曜 0:00（Asia/Tokyo）に、全サーバーのパーティを削除します。掲示板のメッセージ自体は残し、中身を「募集なし」に戻します。公開カードは「日曜リセットで解散しました。」に変わり、ボタンは外れます。

ボットが日曜をまたいで停止していた場合は、次の起動時に1回だけ取りこぼしを処理します。初めて起動したときは削除せず、その時点の直近の日曜を処理済みとして記録します。そのあと作ったパーティが消えるのは、次の日曜です。

## 必要な権限

ボットを招待するとき、次を許可してください。

- チャンネルの閲覧
- メッセージの送信
- メッセージ履歴の閲覧
- アプリケーションコマンド（`applications.commands`）

Privileged Gateway Intents（Message Content、Server Members、Presence）は不要です。

招待URLの例です。`CLIENT_ID` は Developer Portal のアプリケーションIDに置き換えます。権限ビット `68608` は、閲覧、送信、履歴の閲覧です。

```text
https://discord.com/api/oauth2/authorize?client_id=CLIENT_ID&permissions=68608&scope=bot%20applications.commands
```

## セットアップ

Python 3.11 以上を使い、`python` を PATH に通します。`start.bat` が `.venv` を作り、依存パッケージを入れてからボットを起動します。

1. `start.bat` を実行する。
2. 初回は `config.default.yaml` が `config.yaml` にコピーされる。テンプレート自体は残る。
3. トークンが空なので一度止まる。`config.yaml` の `discord_token` にトークンを書く。
4. もう一度 `start.bat` を実行する。

`config.yaml` の項目です。

```yaml
discord_token: "ボットのトークン"
database_path: data/party.db
dev_guild_id: null
```

- `discord_token` は必須です。`config.yaml` は git に含めません。
- `database_path` を空にすると `data/party.db` を使います。
- `dev_guild_id` にサーバーIDを入れると、そのサーバーだけへコマンドを即時同期します。`null` ならグローバル同期で、反映まで最大1時間ほどかかることがあります。開発中にコマンドが二重に出るときは、Developer Portal 側のグローバルコマンドを消してから、ギルドIDを指定して再起動してください。

`start.bat` は `python -B` で起動します。`__pycache__` は作りません。

## ファイル

| ファイル | 役割 |
| --- | --- |
| `bot.py` | 起動、コマンド同期、永続ボタンの登録 |
| `start.bat` | `.venv` の作成、依存パッケージの導入、起動 |
| `config.default.yaml` | 設定のテンプレート |
| `config.yaml` | 初回起動時に作られる、実際に読む設定 |
| `config.py` | `config.yaml` の読み込み |
| `db.py` | SQLite のテーブルと読み書き |
| `service.py` | 作成、参加、退出、リーダー移譲、削除 |
| `views.py` | Components V2 のカード、一覧、掲示板、ボタン |
| `cogs/party.py` | `/party` コマンド |
| `tasks.py` | 日曜 0:00（JST）の全削除 |
